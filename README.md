# Khushi / Billu Jii Birthday Surprise 💜

Mobile-friendly static birthday website for Acode + GitHub Pages.

## Password
`billu`

## BTS card photos
Put these seven files inside `BTS/`:
- rm.jpg
- jin.jpg
- suga.jpg
- jhope.jpg
- jimin.jpg
- v.jpg
- jungkook.jpg

The BTS section is a seven-card slideshow. Each card has a fan-made birthday wish for Khushi / Billu Jii. The site does not claim that BTS personally sent the messages.

## Memories
Replace `Images/photo1.jpg` through `photo10.jpg` with Khushi's photos. Video files are not required and have been removed.

## Music
The existing `Song/soulmate.mp3` behavior is unchanged: it starts after the user enters the memories section, because mobile browsers can block sound autoplay before user interaction.

## GitHub Pages
Upload the contents of this `billu` folder to a repository and enable GitHub Pages from the repository's Pages settings.
